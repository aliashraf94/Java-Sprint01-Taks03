# Task S1.03 level 1.1

## 📌 Goal

This exercise helps practice basic Java skills like:

- Creating classes and objects
- Working with `ArrayList` and `HashSet`
- Avoiding duplicates
- Using loops and iterators

---

## 📁 Files

- `Month.java`: A simple class with a `name` field and `equals()` method to compare months.
- `Main.java`: Main file to create the month list, remove duplicates, and print output.

---

## 🔧 What the Program Does

1. Adds 11 months (without August) to an `ArrayList`.
2. Inserts August in the correct place (index 7).
3. Prints the list in correct order using a `for` loop.
4. Converts the list to a `HashSet` to remove duplicates.
5. Prints the months using an `Iterator`.
